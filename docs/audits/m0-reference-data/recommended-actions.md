## Suggested acceptance criteria for M1/M2

- Every record has exactly one preliminary decision, stable ID, location type, coordinate evidence statement and citation-to-claim mapping.
- Every non-null scientific value is either source-linked with period/unit/resolution, explicitly marked derived with a reproducible method, or clearly labeled unverified atlas claim.
- “No evidence in repository” is distinct from “provider failed” and “phenomenon absent.”
- Every point provider artifact has checked site ID, requested and returned coordinate, period/product/version, raw path/hash, and validator result.
- A `keep_verified` label requires documented review criteria and evidence review; it is never inferred from schema validation or successful API calls alone.
- No scientific source file is edited during normalization or curation.
