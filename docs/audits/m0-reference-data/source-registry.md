# M0 Source registry

**Checked:** 2026-11-15. Repository-stored links and selected official/peer-reviewed records were examined for source identity/product semantics. This is not a claim that every citation supports every attached site value. Record-specific links are listed in [site-by-site audit](site-by-site-audit.md); the registry distinguishes provenance category from claim verification.

## Evidence categories

- `primary_dataset`: provider’s raw response or authoritative dataset metadata; supports only its stated product/parameter and spatial/temporal footprint.
- `peer_reviewed_source`: traceable research paper; supports only its studied location, sample and stated result.
- `official_documentation`: agency/institution documentation about a product, service, or site.
- `atlas_claim`: copied from the supplied structured atlas; not independently verified in M0.
- `derived_value`: deterministic conversion/statistic from a documented input; method/input must remain traceable.
- `unverified`: the available repository evidence does not trace the claim sufficiently.
- `conflicting`: repository evidence records disagreement requiring resolution.

## Candidate future sources (not integrated)

### 1. USGS Terrestrial Analogs Data Portal (TADP) and ScienceBase — highest relevance

USGS describes TADP as a digital repository and discovery portal for Earth data relevant to planetary science; it exposes analog types and catalogs archived field data through ScienceBase. ScienceBase provides REST/JSON access and search. TADP can contribute site metadata and field datasets with explicit archive records; it is the best first discovery source for analog-specific provenance. It does not guarantee that every TerraMatch site has a record, that every dataset has coordinates, or that a record is an authoritative synthesis. Match by dataset/field locality, not only place-name. Review item-specific rights and citations before reuse; USGS public data releases commonly state rights per item. [TADP](https://tadp.astrogeology.usgs.gov/), [ScienceBase API documentation](https://www.usgs.gov/sciencebase-instructions-and-documentation/api-and-web-services), [TADP contribution metadata requirements](https://tadp.astrogeology.usgs.gov/how-to-contribute). No authentication claim is made for all services; read-only public catalog access is documented, while contribution requires metadata/validation.

### 2. USGS Planetary Aeolian Analog Database (PAAD) — high value for dunes

USGS PAAD v1 is a data release of 45 dune field sites with bedform, climate class, sand source/composition, latitude/longitude, elevation and approximate areal coverage. It is directly relevant to Lut, White Sands and other dune analogs, but it is domain-specific and the described attributes are not complete for every field site. Obtain the ScienceBase data release/download and cite its DOI; repository listing says CC0 1.0. Geographic coordinate/site footprints and attribute citation provenance still need individual review. [USGS PAAD release, DOI 10.5066/P9IFVZEX](https://www.usgs.gov/data/paad-planetary-aeolian-analog-database).

### 3. EarthChem / PetDB — targeted geochemistry, not a generic site catalogue

EarthChem provides search/access across geochemical, geochronological and petrological sample databases; PetDB is appropriate for sample-level chemical data where a named site/sample is represented. Access includes web portal and developer/API documentation. Location matching depends on sample metadata and original citations; samples may not represent the analog footprint. License varies by dataset. EarthChem requires adequate citation; dataset DOIs and individual data licenses should be retained. [EarthChem](https://earthchem.org/), [terms/citation](https://earthchem.org/legal/terms-of-use), [developer docs](https://earthchem.github.io/ec-doc/). Do not use a nearby rock analysis as proof of the map polygon’s mineralogy.

### 4. GEOROC — targeted volcanic/geochemical samples

GEOROC contains published geochemical analyses of igneous and metamorphic rocks/minerals, analytical metadata, ages and references, with a current institutional API project documented by the University of Göttingen/DIGIS ecosystem. Potentially useful for Etna, Kilauea, Iceland, Pilbara and other volcanic sites only when sample locality is traceable. It is not a planetary-analog classification or climate/terrain dataset. Access/download/API and attribution terms should be checked for the specific endpoint/export; cite original papers. [GEOROC](https://georoc.eu/), [DIGIS API notebook/example](https://github.com/digis-georoc/Georoc_jupyter).

### 5. NASA Planetary Data System (PDS) — Mars-side comparison context

PDS is a federated archive for planetary mission and research products, with a registry/search API. It can improve the Mars-side context (e.g., rover/remote sensing product provenance, data product resolution and periods), not supply Earth reference measurements. Access is through node/product APIs and downloads; authentication/terms vary by collection and underlying product. PDS data should be cited by dataset/product identifier and its label/metadata. [PDS API docs](https://nasa-pds.github.io/pds-api/), [PDS search](https://pds.nasa.gov/services/search/index.jsp).

## Source-selection ranking

1. **TADP / ScienceBase:** best alignment with analog-specific field data and traceable archive records.
2. **PAAD:** practical, directly relevant structured dune-site dataset with DOI and CC0 status reported by USGS.
3. **EarthChem / GEOROC:** high value for sample chemistry only after exact locality/sample matching and license review.
4. **PDS:** improves Mars evidence and comparison metadata rather than Earth reference coverage.

Do not add an integration until a source fills a documented dimension gap, has stable metadata/access, permits intended display/reuse, and has a defensible site-coordinate or sample association. No new dataset was downloaded in this audit.
