# Targeted Site Selection

Selection used the M1 decisions and the M2 site/source matrix. Four targets were chosen because the sources offer a plausible, narrow dataset path and each target represents a distinct analog dimension. The other 27 records remain in the archive and were not demoted or removed.

| Site | Target source | Why selected | Outcome |
|---|---|---|---|
| MET — Meteor Crater | USGS TADP/ScienceBase and USGS publication/data release | A named impact structure with a direct planetary impact-process rationale. Official USGS reporting contains site-study geochemistry and points to a data release. | Report Table 1 acquired; mount-average glass composition is associated with the named study area, but individual mount coordinates are not in the table. ScienceBase item API was blocked; linked full release not downloaded. |
| ETN — Mount Etna | GEOROC | Volcanic materials and mineral/component geochemistry are relevant, and a catalog query can target a bounded region around the curated marker. | Four FeOt rows for GEOROC sample label SDV-1 retrieved. Its coordinate bounds (37–38.5 N, 14–16 E) are regional, so these rows do not validate the marker or all of Etna. |
| WHS — White Sands | PAAD | A dune-field reference is directly relevant to aeolian analog research; PAAD is specifically a dune-field database with bedform and sand-context attributes. | Targeted PAAD/ScienceBase catalog query returned HTTP 403. No dataset row acquired. |
| RTI — Río Tinto | EarthChem/PetDB | Site-specific sample geochemistry could inform the hydrothermal/acidic environment evidence dimension if coordinates and sample context match. | Two documented bounding-box API attempts returned HTTP 502. No sample row acquired. |

No record was selected solely because it already has NASA POWER, DEM, or GLiM evidence. The target set is an acquisition shortlist, not a statement that the sources represent all sites or that the sites are validated Mars analogs.
