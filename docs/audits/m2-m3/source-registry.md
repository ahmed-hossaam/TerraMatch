# M2 source registry

| Source | Official documentation / data | Access and contents | Attribution, licensing and key limitations |
|---|---|---|---|
| USGS TADP | [TADP](https://tadp.astrogeology.usgs.gov/); [ScienceBase API](https://www.usgs.gov/sciencebase-instructions-and-documentation/api-and-web-services) | Search/catalog portal backed by ScienceBase; item JSON and attached release files. Dataset variables, scale, license, and coordinate meaning are specific to each item. | Catalog discovery is not a site match. M2 test request was blocked by an anti-bot challenge. Review each item’s metadata, DOI, extent, and terms. |
| PAAD v1 | [USGS data release](https://www.usgs.gov/data/paad-planetary-aeolian-analog-database); [DOI 10.5066/P9IFVZEX](https://doi.org/10.5066/P9IFVZEX) | USGS release: 45 dune-field sites; bedforms, climate class, sand source/composition, coordinates, average elevation, approximate area. Download via linked ScienceBase data release. | USGS marks release CC0 1.0. Dune-focused, approximate area is not sample precision, and attributes may be region/site summaries. It cannot cover all analog types. |
| EarthChem / PetDB | [PetDB API documentation](https://earthchem.github.io/ec-doc/documentation/petdb_api.html); [developer resources](https://ftp.earthchem.org/resources/developers); [EarthChem terms](https://earthchem.org/legal/terms-of-use); [current portal notice](https://search.earthchem.org/) | Documented PetDB v4 routes include sample, location, citation, and export queries; geochemical variables, units and methods are record-specific. PetDB 2.0 is separately documented; old portal notice says legacy PetDB was taken offline. | Collection and dataset terms differ; data users must check the terms and citation metadata for the exact dataset. Cite original papers. A sample’s coordinates and precision must be reviewed; no site association based on place name alone. M2 did not access sample records. |
| GEOROC | [Current query portal](https://georoc.eu/georoc/new-queryBlank.asp); [precompiled datasets](https://georoc.eu/georoc/precompiled/); [citation guidance](https://georoc.eu/georoc/cite.asp); [disclaimer](https://georoc.eu/georoc/disclaimer.asp) | Search/download interface and precompiled CSV files, with samples, geochemistry, coordinate, method, laboratory and reference metadata. No stable public API was verified for this task. Large precompiled files can be multi-gigabyte. | Query compilations are CC BY-SA 4.0 and require attribution to GEOROC plus original sources; repository data can have separate terms. Curators warn of missing metadata and older methods. No broad files were downloaded. |

Official source documentation was reviewed on 2026-11-15. M2 retrieval results are reported separately in `M2-source-integration-report.md`; documentation review does not count as data retrieval.
